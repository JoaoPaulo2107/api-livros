## 📌 Sobre o Projeto

A **API de Livros** é uma aplicação web completa (Full-Stack) desenvolvida para gerenciar um acervo bibliográfico. O projeto integra um backend moderno em Python criado para expor serviços RESTful, um banco de dados relacional para persistência das informações, e uma interface gráfica no frontend para interação direta do usuário.

---

## 🚀 Etapas do Desenvolvimento

O roteiro do projeto foi estruturado de forma progressiva em **4 fases principais**:

- [x] **Etapa 1: Fundação (FastAPI & MySQL)**
  * Configuração inicial do servidor web com FastAPI.
  * Estabelecimento da conexão com o banco de dados relacional (MySQL).

- [ ] **Etapa 2: Modelagem e Rotas Iniciais (POST e GET)**
  * Criação dos modelos de dados (entidade Livro).
  * Desenvolvimento das rotas para criação de novos registros (`POST`) e leitura/listagem dos dados (`GET`).

- [ ] **Etapa 3: Conclusão do CRUD (PUT e DELETE)**
  * Implementação da rota de atualização de registros existentes (`PUT`).
  * Implementação da rota de exclusão de registros (`DELETE`), completando o ciclo do CRUD.

- [ ] **Etapa 4: Interface de Usuário (Frontend)**
  * Criação da interface gráfica utilizando HTML, CSS e JavaScript.
  * Integração do frontend com as rotas da API via requisições assíncronas (Fetch API/Axios).
